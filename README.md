# DJI-Osmo-Action-4
DJI Osmo Action 4 是一款专为户外运动和日常记录设计的运动相机，凭借大底传感器、强悍防抖和出色的低温适应性，成为许多户外爱好者的首选。核心影像能力：搭载 1/1.3 英寸 CMOS 传感器，等效像素尺寸达 2.4 μm，配合 f/2.8 光圈，在日出日落等大光比及低光环境下依然能拍出细节丰富、动态范围出色的画面；支持 4K/120fps 超清慢动作，能清晰捕捉飞溅的水花等高速瞬间，155° 超大广角带来强烈的视觉冲击和空间纵深感；支持 10-bit 色深和 D-Log M 色彩模式，可记录超 10 亿种色彩，保留更多高光和阴影细节，为后期调色提供充足空间。强悍机身与防抖：配备超强增稳 RockSteady 3.0 和 360° 地平线增稳 HorizonSteady，即使在摩托车压过碎石路或剧烈颠簸时，也能过滤高频震动，保持画面如轨道般平稳水平；裸机防水深度达 18 米，支持湿手操作，搭配官方防水壳可下潜至 60 米；耐寒长续航电池在 -20℃ 严寒环境下仍能稳定工作，常温下最长续航可达 160 分钟，并支持快充，充电 18 分钟即可恢复 80% 电量。智能与便捷功能：采用磁吸底座设计，拆装顺滑且不伤漆面，单手即可快速切换横竖拍构图；配备前后双触摸彩屏，交互直观，戴手套时触控依然灵敏；支持预录制、高光时刻标记、自拍杆消除及 GPS 仪表盘等智能辅助功能。套装与配件选择：标准套装（相机主机、电池、磁吸底座等基础配件）适合日常记录、轻度户外及已有配件的用户；全能套装（标准套装 + 额外2块耐寒长续航电池 + 1.5米延长杆）适合长途旅行、滑雪、需要长时间拍摄和自拍的用户；Vlog 套装（相机 + DJI Mic 系列麦克风 + 迷你延长杆）适合对音质有较高要求的 Vlog 创作者；另有骑行/潜水等专项套装供特定运动爱好者选择。选购建议：新手或偶尔拍摄选标准套装即可；计划长途旅行、滑雪或高强度户外活动，强烈建议选择全能套装，多出的电池和延长杆能解决续航和自拍两大痛点；存储卡需单独购买，建议选择 V30/A2 等级以上的 microSD 卡（如雷克沙 1066x 系列），以确保 4K/120fps 高码率录制的稳定性。
