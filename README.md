# DJI-Osmo-Action-4
DJI Osmo Action 4 是一款专为户外运动和日常记录设计的运动相机，凭借大底传感器、强悍防抖和出色的低温适应性，成为许多户外爱好者的首选。核心影像能力：搭载 1/1.3 英寸 CMOS 传感器，等效像素尺寸达 2.4 μm，配合 f/2.8 光圈，在日出日落等大光比及低光环境下依然能拍出细节丰富、动态范围出色的画面；支持 4K/120fps 超清慢动作，能清晰捕捉飞溅的水花等高速瞬间，155° 超大广角带来强烈的视觉冲击和空间纵深感；支持 10-bit 色深和 D-Log M 色彩模式，可记录超 10 亿种色彩，保留更多高光和阴影细节，为后期调色提供充足空间。强悍机身与防抖：配备超强增稳 RockSteady 3.0 和 360° 地平线增稳 HorizonSteady，即使在摩
